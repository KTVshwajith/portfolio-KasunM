# Kasun Moolikagedara — Portfolio

Personal portfolio of Kasun Moolikagedara, PhD: research in video authentication and computer vision, live in-browser demos, app projects and publications.

**Live site:** https://ktvshwajith.github.io/portfolio-KasunM/

## Demos
- **Tamper-evident video chain:** frames are split into blocks, hashed with SHA-256 and chained; altering a frame is detected and located. Runs entirely in the browser (Web Crypto API).
- **Pose angle analysis:** 33-landmark pose estimation (MediaPipe BlazePose) measures joint angles from a photo or webcam, on-device.

## Files
- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `kasun.jpg`, `presenting-poster.jpg`, `presenting-audience.jpg` — photos
